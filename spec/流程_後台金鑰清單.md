# 後台金鑰清單流程

## 觸發

管理員登入後台後，於左側導覽點「Tokens list」進入金鑰（登入 token）清單頁（`LayoutContentTokens.vue`）。此頁列出系統現存的登入 token（SSO session），提供管理員檢視、調整時間欄、刪除（撤銷 session）與儲存。

後端 `getTokensList` / `updateTokensList` 皆以 `funCheckAdmin` 包裝（`server/WWebSso.mjs:1382,1389`），**僅具 admin 權限的有效 token 可存取**；token 無效／過期／非 admin 一律 reject。

## 執行流程

```
001  管理員點 Save, 觸發 saveTokens  [LayoutContentTokens.vue]
002      執行非同步流程 core()
003          開啟 loading
004          檢查 isError  [LayoutContentTokens.vue:852]
005              註: isError computed 恆回傳 ''  [LayoutContentTokens.vue:471]
006                  → 此分支為死碼, 永遠不進入 (showCheckYes 不會被觸發)
007          取得當前 opt.rows 與 admin token
008          呼叫後端 updateTokensList(token, rows)  [LayoutContentTokens.vue:872]
009              checkToken(token, {fun: funCheckAdmin})  [procCore.mjs:1710]
010                  token 無效 / 過期 / 非 admin:
011                      reject  → errTemp 被設值
012              updateTabItems('tokens', rows, 'id', {resetOrder:false}) 差異更新  [procCore.mjs:1700]
013          檢查 errTemp  [LayoutContentTokens.vue:878]
014              非 null (後端 reject):
015                  關 loading, 顯示 System message modal 儲存失敗訊息, return  [LayoutContentTokens.vue:879]
016          isModified = false
017          關 loading, 顯示 System message modal 儲存成功訊息  [LayoutContentTokens.vue:888]
018      .catch
019          非預期例外 → console.log + $alert toast (anUnexpectedErrorOccurred)
020      .finally
021          關 loading (一處關閉)
```

## i18n 訊息粒度規則

| 觸發情境 | i18n 鍵 (grep `server/procLang.mjs`) | 顯示元件 | 規則 |
|---|---|---|---|
| 儲存成功 | `tokenSaveTokensSuccess` | `showCheckYes` 持久 modal（System message） | 管理員須點 OK 確認讀過 |
| 儲存失敗（後端 reject） | `tokenSaveTokensFail`（後接錯誤字串） | `showCheckYes` 持久 modal | 同上 |
| 非預期例外（外層 catch） | `anUnexpectedErrorOccurred` | `$alert` toast（4 秒自動消失） | 非預期錯誤刻意低調呈現，不阻斷 |

實際翻譯文字 → 寫測試時 grep `server/procLang.mjs` 對應鍵後直接讀取。

## 參數來源

| 概念 | 來源 | 流程影響 |
|---|---|---|
| 操作者 token | 前端 store（登入後 admin token） | 後端以 `funCheckAdmin` 驗證；失效則 Save reject 走失敗 modal |

## spec 規則摘要

- **權限**：`getTokensList` / `updateTokensList` 皆 admin-only（`funCheckAdmin`）。
- **粒度**：操作結果（成功 / 失敗）一律 `showCheckYes` 持久 modal（須確認讀過、可做 e2e pixel + 語意斷言）；非預期例外才用 `$alert` toast。
- **邊界**：`isError` 恆為 `''`，前端驗證攔截分支為死碼；無「手動新增」列。刪除某列即撤銷該 session。
- **契約**：Save 前開 loading、`finally` 一處關 loading；每個 `await showCheckYes(...)` 前先關 loading（modal 阻斷，避免 loading 疊著）。
