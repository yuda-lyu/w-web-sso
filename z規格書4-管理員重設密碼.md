# 規格書 4：管理員重設密碼

> 依賴：規格書 1（passwordPolicy）、規格書 2（密碼生成與驗證引擎）、規格書 3（使用者表結構擴充）
> 被依賴：規格書 5（使用者透過連結變更密碼）


## 一、目的

管理員於後台 Users list 點擊「Reset password」後，系統執行以下動作：
1. 標記目標使用者帳號為「待變更密碼」（禁止登入）
2. 產生密碼重設 token 並設定過期時間
3. 寄送含重設連結的 Email 通知目標使用者

管理員**不需要輸入新密碼**，也**不會看到任何密碼**。使用者必須自行透過信件連結設定新密碼（見規格書 5）。


## 二、完整流程

```
管理員點擊「Reset password」
  → 前端跳出確認對話框（顯示目標使用者名稱）
    → 管理員確認
      → 呼叫 API：resetUserPassword(token, lang, userId)
        → 後端：
          1. 驗證管理員 token 有效
          2. 驗證管理員為 admin
          3. 查詢目標使用者（確認存在且有效）
          4. 產生 passwordResetToken（UUID）
          5. 計算過期時間（now + passwordPolicy.resetExpireHours）
          6. 儲存至目標使用者：
             - isPendingPasswordReset = 'y'
             - passwordResetToken = 生成的 token
             - timePasswordResetExpired = 過期時間
          7. 清除該使用者所有現有登入 token（強制登出）
          8. 寄送 Email（含重設連結）
        → 回傳成功
      → 前端顯示成功訊息
```


## 三、後端實作

### 3.1 procCore.mjs — 新增 resetUserPasswordByAdmin

```
位置：接續 checkTokenAndChangePassword 之後（約 line 798）
```

**函式簽名：**
```javascript
let resetUserPasswordByAdmin = async (token, lang, userId) => { ... }
```

**邏輯步驟：**

```
1. checkToken(token) — 驗證管理員 token

2. 取得管理員身份：
   let admin = await getUserByToken(token)
   if (get(admin, 'isAdmin') !== 'y') → reject('permission denied')

3. 驗證目標 userId：
   if (!isestr(userId)) → reject('invalid userId')
   let targetUser = await _getGenUserByKV('id', userId)
   if (!iseobj(targetUser)) → reject('user not found')

4. 產生 resetToken：
   let resetToken = genIDSeq()

5. 計算過期時間：
   let expireTime = ot().add(passwordPolicy.resetExpireHours, 'hour')
                        .format('YYYY-MM-DDTHH:mm:ss.SSSZ')

6. 儲存至資料庫：
   await woItems.users.save({
       id: userId,
       isPendingPasswordReset: 'y',
       passwordResetToken: resetToken,
       timePasswordResetExpired: expireTime,
   })

7. 清除該使用者所有現有 token（強制登出）：
   let tokens = await woItems.tokens.select({ userId: userId })
   for each token → await woItems.tokens.del({ id: token.id })

8. 寄送 Email（non-blocking）：
   try {
       let resetUrl = `${baseUrl}/?view=resetPassword&resetToken=${resetToken}`
       // 組合 email 標題與內容
       await srEmail.send(sender, title, content, targetEmail)
   } catch (err) {
       srLog.error(...)
   }
```

**匯出：** 加入 return 的 `p` 物件

### 3.2 WWebSso.mjs — 新增 API

```javascript
resetUserPassword: async (_t, token, lang, userId) => {
    srLog.info({ event: 'kpfun-resetUserPassword', token, lang, userId })
    let r = await p.resetUserPasswordByAdmin(token, lang, userId)
    return r
},
```

### 3.3 baseUrl 取得

重設連結需要完整的 URL。需在 WWebSso.mjs 中組合 baseUrl 並傳入 procCore：

```javascript
// WWebSso.mjs 中組合
let baseUrl = `http://localhost:${serverPort}${subfolder}`
// 或從 settings.json 新增 baseUrl 設定，讓使用者自行指定外部可存取的 URL
```

建議在 `settings.json` 新增：
```javascript
baseUrl: 'http://localhost:8080',  // 外部可存取的站台 URL
```


## 四、前端實作

### 4.1 LayoutContentUsers.vue — modifyItemPasswordById 改造

**從複雜表單簡化為確認對話框：**

因為管理員不需輸入密碼，只需確認操作，所以改用簡潔的確認流程。

```javascript
modifyItemPasswordById: function(id) {
    let vo = this

    // 查找目標使用者
    let rows = get(vo, 'opt.rows', [])
    let targetUser = null
    each(rows, (v) => {
        if (get(v, 'id', '') === id) {
            targetUser = v
            return false
        }
    })

    if (!iseobj(targetUser)) {
        vo.$alert(vo.$t('userEditNoUserData'), { type: 'error' })
        return
    }

    let targetName = get(targetUser, 'name', '')
    let targetAccount = get(targetUser, 'account', '')

    // 確認對話框
    vo.$alert(
        `${vo.$t('adminResetPasswordConfirm')}: ${targetAccount} (${targetName})`,
        {
            type: 'warning',
            showCancel: true,
            onOk: async () => {
                try {
                    vo.$ui.updateLoading(true)
                    let token = vo.userToken
                    let lang = vo.$store.state.language || 'eng'
                    await vo.$fapi.resetUserPassword(token, lang, id)
                    vo.$alert(vo.$t('adminResetPasswordSuccess'))

                    // refresh 列表以更新 isPendingPasswordReset 狀態
                    // ...
                } catch (err) {
                    vo.$alert(`${vo.$t('adminResetPasswordFail')}: ${err}`, { type: 'error' })
                } finally {
                    vo.$ui.updateLoading(false)
                }
            },
        }
    )
},
```

> 備註：若 `$alert` 不支援 `showCancel` / `onOk`，則需改用其他確認機制（如 data 狀態控制顯示一個確認區塊），依實際 w-component-vue 的 `$alert` API 而定。
